# TP1 - Análisis exploratorio de C-MAPSS

Organización de Datos / Ciencia de Datos (FIUBA) - Santiago Jorda

Análisis exploratorio del dataset de la NASA de degradación de motores turbofan (C-MAPSS), con consultas en Pandas y en Spark (API de RDDs).

**Notebook en Colab:** https://colab.research.google.com/github/santiagojorda/ciencia-de-datos-tp1/blob/entrega-tp1/TP1.ipynb

## Cómo correrlo

Abrir el link de arriba y ejecutar todas las celdas (Entorno de ejecución → Ejecutar todas). La primera celda clona el repositorio para tener la carpeta `data/` e instala Java 17 y PySpark.

## Archivos

- `TP1.ipynb`: el notebook de la entrega.
- `TP1.py`: el mismo notebook en formato texto (jupytext), para revisar los cambios en git.
- `data/`: los archivos del dataset (train, test y RUL de FD001 a FD004).
- `readme.txt`: el readme original del dataset.
